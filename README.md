# Fee Slip Template Builder (React)

A configurable React.js template builder to generate fee slips for multiple schools.

## Features
- Customize school branding (name, address, logo upload or URL)
- Choose between multiple template designs (Classic / Modern / Minimal)
- Set header, footer, and accent colors
- Edit student and receipt metadata
- Add/remove/edit fee rows dynamically
- Auto-calculation for subtotal, tax, and grand total
- Live preview of the fee slip template

## Run locally
```bash
npm install
npm run dev
```

Then open the URL printed by Vite (default `http://localhost:5173`).
